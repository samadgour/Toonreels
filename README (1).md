# Toonreel Club

A single-page animated movie catalogue. Browse by genre, search for movies, read summaries, and save favourites to a personal watchlist.

## Features

- Browse animated movies with posters, ratings, year and director
- Filter by genre (Action, Adventure, Comedy, Drama, Fantasy, Mystery, Romance, Sci-Fi)
- Search by title
- Tap a movie to read its full summary
- Watchlist: tap the brain button on any card (or in the movie popup) to add or remove it. Open your saved movies with the Watchlist button in the header
- Watchlist is saved in your browser, so it stays after a refresh
- Light, dark and auto theme, plus a reduce-motion option (hamburger menu)
- Works on phones and desktops

## Tech

- HTML, CSS and vanilla JavaScript in one file (`index.html`)
- Movie data from the free [OMDb API](https://www.omdbapi.com/)
- No build step and no dependencies

## Deploy on GitHub Pages

1. Create a public repository and upload `index.html` to it.
2. Go to **Settings**, then **Pages**.
3. Under Source, choose **Deploy from a branch**, select `main` and `/ (root)`, and click **Save**.
4. After a minute or two, the site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
